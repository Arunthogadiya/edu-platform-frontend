# Please add your face image here

To test the face recognition system:

1. Add a clear, front-facing photo of yourself as `Vipin.jpg` in this directory
2. The image should be in JPG format
3. Recommended size: 300x300 pixels minimum
4. Good lighting and clear visibility of facial features
5. Only one face per image

Once you add the image, the face recognition system will be able to detect and recognize your face during attendance.
